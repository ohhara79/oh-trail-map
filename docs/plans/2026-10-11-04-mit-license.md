# MIT license

## Context

The repo had no license, so nobody else could legally reuse it. The user wants the
app used freely with as few restrictions as possible, and chose MIT over 0BSD /
Unlicense and Apache-2.0.

MIT can only cover the user's own work. The map tiles and terrain under
`data/tiles/` and the National Point Number data keep their own terms, so the
README says so.

## Change

1. `LICENSE`: the standard MIT text, `Copyright (c) 2026 Taeho Oh`.
2. `package.json`: `"license": "MIT"`.
3. `README.md`: a `## License` section — the code is MIT; the tiles, terrain and
   national points data are not relicensed, and the tiles are credited behind the ⓘ.

## Verification

1. `npm run build` passes.
2. `LICENSE` matches the SPDX `MIT` text.
