# Commit the trails and map tiles

## Context

The app bundles trails from `data/gpx/` and serves map tiles from `data/tiles/`
(README *Map tiles*), but both directories were untracked, so a fresh clone had
no trails and a blank map. The user wants them in the repo.

- `data/gpx/`: 51 `.gpx` files, 14 MB
- `data/tiles/`: 38,816 `.png` files, 313 MB (osm 249 MB, topo 50 MB, terrain 15 MB)

No file is over 50 MB, so GitHub's 100 MB limit isn't hit and git-lfs isn't
needed.

## Change

1. `git add data/gpx data/tiles`. Nothing else: the other untracked files
   (`backup/`, `log`, `r.sh`) stay out.
2. Commit as "Add the trails and the 관악산 map tiles".

## Verification

1. `git show --stat HEAD | tail -1` reports 38,867 data files added.
2. `git status --short data` prints nothing.

## Follow-up

- Not pushed: it adds ~330 MB to `origin`. If the repo is public, a push also
  publishes the GPX tracks, so the user decides when to push.
