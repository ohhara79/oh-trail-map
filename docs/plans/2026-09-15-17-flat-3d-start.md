# Open 3D looking straight down, like 2D

## Context

Switching from 2D to 3D opens the orbit camera tilted 60°. The user wants 3D to open the
way 2D looks: straight down with north up. That's the same view the 3D compass gives when
you press it (it resets bearing and pitch to 0).

The tilt comes from `src/view3d.ts:139`, where `new MlMap({... pitch: ORBIT_PITCH })` uses
`ORBIT_PITCH = 60` (`src/view3d.ts:99-100`). No bearing is passed, so it's already 0.

## Change

1. **`src/view3d.ts`, map constructor.** Remove `pitch: ORBIT_PITCH` so MapLibre uses its
   default pitch of 0, the same as the compass reset. Add a short comment: 3D opens flat
   and north-up, like 2D and the compass reset. Keep `maxPitch: ORBIT_MAX_PITCH` so
   dragging can still tilt.
2. **`ORBIT_PITCH` stays** for the walk → orbit return (`src/view3d.ts:368`). Leaving walk
   mode at zoom 16 looking straight down would lose the direction you were facing. Change
   the doc comment on `ORBIT_PITCH` to say where it's used now: the orbit camera you
   return to after walking.
3. **Plan doc.** Save this plan as `docs/plans/2026-09-15-17-flat-3d-start.md`, in the
   same style as the other plan docs.

## Verification

1. `npm run build` passes.
2. `npm run dev`, then in 2D pan, zoom and press 3D:
   - The 3D view opens straight down and north-up at the same place and scale, and looks
     like 2D with terrain shading.
   - The compass shows no tilt, and pressing it changes nothing.
   - Dragging with the right button or Ctrl, or with two fingers, still tilts and turns.
   - Walk → Orbit still comes back tilted, facing the way you were walking.
