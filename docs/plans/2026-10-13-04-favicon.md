# Add a favicon.ico

## Context

The site has no favicon, so browsers show a blank tab icon and request
`/favicon.ico`, which the S3 bucket answers with a 403. Add a small
mountain-and-trail icon that matches the map's look (chosen by the user).

## Change

1. Add `scripts/make-favicon.py` (next to `scripts/fetch-tiles.py`), using
   Pillow (already installed, 9.0.1). It draws the icon at 256×256 and saves
   `public/favicon.ico` with sizes 16, 32, 48 and 64:
   - green rounded square background (map-park green, e.g. `#4c9a4a`);
   - a white mountain peak (two overlapping triangles);
   - a thick winding trail line in a trail colour (e.g. magenta `#d63aa8`)
     climbing to the peak;
   - one brown point dot with a white rim (`#b5560f`, like the map's points)
     on the summit.
   Keep shapes bold so they still read at 16×16. Check the result by viewing a
   scaled-up PNG render and tweak if needed.

2. Commit the generated `public/favicon.ico`. Vite copies `public/` into
   `dist/`, the same as `og.png` and `robots.txt`.

3. Add `<link rel="icon" href="/favicon.ico" sizes="any" />` to `index.html`
   after the `<title>` line, so the icon is found explicitly, not just by the
   default `/favicon.ico` request.

4. `d.sh` (untracked) uploads files by name, so add after the `robots.txt` line:

   ```sh
   aws s3 cp dist/favicon.ico $B/favicon.ico --cache-control "public,max-age=604800"
   ```

5. Save this plan as `docs/plans/2026-10-13-04-favicon.md`, following the repo's
   plan convention.

## Verification

1. `python3 scripts/make-favicon.py` writes `public/favicon.ico`;
   `file public/favicon.ico` reports an icon with 4 sizes.
2. `npm run build` passes and `dist/favicon.ico` exists; `dist/index.html`
   holds the `<link rel="icon">` tag.
3. `npm run preview` and the browser tab shows the icon.
4. After deploying with `d.sh`, `curl -I https://gwanaksan.ohhara.ai/favicon.ico`
   returns 200.
