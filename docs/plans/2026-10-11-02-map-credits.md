# Map credits behind a tiny ⓘ

## Context

The app is about to go public. [2026-08-26-05](2026-08-26-05-remove-map-attribution-control.md)
removed the on-map attribution box. It was defensible then because exported PNGs and SVGs
still carried each source's credit, and only the operator saw the live view. Neither
holds now: [2026-09-13-05](2026-09-13-05-remove-export-carto-width-uniform.md) removed
the exporter, and a public site is seen by everyone. The tiles under `data/tiles/` come
with attribution terms:
- OSM: ODbL.
- OpenTopoMap: CC-BY-SA.
- AWS / Mapzen Terrain Tiles: credit the sources they list.

None of them were credited anywhere. This reverses 2026-08-26-05 in a form small
enough to keep its point, a clean map.

The user picked the place: the 12px strip above `#view3d`, the one gap left in the
top-right column, so the 3D button doesn't move. It fades with the rest of the
chrome during 3D playback.

## Change

1. **`src/basemaps.ts`:**
   - Every `Basemap` gets a `credit` (HTML): OSM, OpenTopoMap (CC-BY-SA), and Esri
     for when `SATELLITE_ENABLED` is on.
   - `TERRAIN_CREDIT` is added. It is always shown, because the 2D readout reads
     the terrain as well as 3D.
2. **`src/credits.ts`** (new):
   - `createCredits(basemap)` fills `#credits-text` with the basemap's credit and
     the terrain's, and makes the links open in a new tab.
   - The ⓘ toggles the box. A pointerdown outside it, or Escape, closes it.
   - `setBasemap` swaps the text.
3. **One element over both views**, not a Leaflet control plus a MapLibre one. Both
   maps keep `attributionControl: false`, so 2D and 3D show the same thing in the
   same place.
4. **`index.html`:** `#credits` (the toggle and the hidden text) follows `#view3d`.
5. **`src/main.ts`:** creates the credits after `createMap`, and `setBasemap` updates them.
6. **`src/style.css`:**
   - `#credits` is 34px wide at `top: env(safe-area-inset-top)`, so it is centred
     over `#view3d`.
   - The toggle is a 34×12px borderless ⓘ in `--muted`.
   - The text box opens to its left, with the button chrome's border and radius.
   - `#credits` is added to both chrome-fade lists, and to `CHROME` in `src/hud3d.ts`.
7. **`README.md`:** a feature bullet.

## Verification

1. `npm run build` passes.
2. 2D, desktop: the ⓘ sits above the 3D button without touching it. A click opens
   the OSM and terrain credits to its left. A click elsewhere, or Escape, closes them.
3. Switch to OpenTopoMap with the box open. The text changes to the OpenTopoMap credit.
4. 3D orbit and walk: the ⓘ stays and works. Playback: a tap that fades the chrome
   fades it too.
5. Phone width: the open box fits on screen and clears the 3D button.

## Follow-up

- The ⓘ is a 34×12px target, small for a thumb. The user chose it to keep the 3D button
  where it is. If it proves hard to hit, the fallback is a chip beside or below `#view3d`.
